# Каталог программ «Без подписки»

Сайт: https://pavelb-22.github.io/ — открывается по кнопке «📦 Все программы» в Telegram-канале.

## Добавить новую программу
Допиши запись в `programs.json` (по образцу), положи иконку в `icons/`, затем `bash publish.sh`.
Через 1–2 минуты программа появится на сайте. Пост в канале переписывать не нужно.

## Ознакомительный пост с кнопкой
1. `bash secrets.sh` — добавить токен бота и ID канала в секреты репозитория.
2. GitHub → репозиторий → Actions → «Post intro» → Run workflow.
3. Закрепить пост в канале.
